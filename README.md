
# AutoParts Medellín — Inventory & Sales Dashboard

## Abstract
Power BI dashboard centralizing inventory, sales, and scrap KPIs across 5 retail stores in Medellín, Colombia. Built on 1,000 simulated purchase orders (2024).

| File | Description |

| `erp_autoparts.pbix` | Power BI dashboard |
